# 云造墨水屏项目集

面向 **Metalio E-INK4 / E-INK4 Plus 墨水屏设备**的应用开发与系统集成实践，由**李昌开实验室**整理维护。

这个项目尝试回答一个简单的问题：**一块墨水屏，能否不只是一台用途固定的设备，而是随着需求变化，承载不同的小应用？**

围绕这个目标，我们持续探索应用固件的设计、生成、切换和数据保存，并把过程中形成的接入约定、应用成果与通用组件整理在这里。

## 项目在做什么

- **固件口袋**：探索让多个独立应用通过统一入口被发现和启动，减少每换一种用途就重新组织整套设备使用流程的成本。
- **应用接入规范**：定义应用身份、运行模式、退出返回、必要数据保存等共同约定，让不同应用在保留自身功能和界面设计的同时，能够遵循一致的接入方式。
- **具体应用实验**：围绕墨水屏适合的轻量交互场景开展实践，例如二维码凭证展示与核销。
- **可复用组件**：把开发中反复遇到的共性问题独立处理，例如适用于 Plus 设备的黑白中文字体、字库准备与绘制。
- **AI 辅助开发**：探索以自然语言描述需求、由 AI 辅助完成固件开发和测试的工作方式，并通过明确的接口约定减少不同应用之间的集成成本。

这里的重点不只是某一个功能，而是**从具体应用出发，逐步形成可以继续扩展的设备应用体系**。

## 仓库里有什么

| 目录 | 主要内容 |
| --- | --- |
| [`protocols/`](protocols/) | 固件口袋的接入规范、开发指南，以及 Skill 生成固件的最小集成兼容协议与历史版本 |
| [`firmware-pocket/`](firmware-pocket/) | 固件口袋相关的阶段性交付包 |
| [`亮证/`](亮证/) | 二维码凭证展示与核销应用的相关交付材料 |

各目录记录的成果类型不同：有的是规范文档，有的是组件源码与工具，也有的是打包交付文件。请根据自己的目的选择入口。

## 建议从这里开始

**想先理解应用如何接入固件口袋？**

阅读 [《固件口袋接入规范与开发指南》](protocols/固件口袋接入规范与开发指南.md)。其中介绍了应用需要声明什么、如何区分独立运行与口袋集成、怎样处理保存和返回，以及开发前需要准备的设备信息。

**想了解多个固件之间的共同约定？**

阅读 [《Skill 生成固件的最小集成兼容协议》](protocols/Skill生成固件的最小集成兼容协议.txt)，了解这套开发方式希望保持一致的基本规则。

**想在 Plus 墨水屏应用中使用中文黑白字体？**

从 [Plus 黑白字体组件 README](plus-noto-font/README.md) 开始。该子项目提供现成字号与字重、字库准备命令、C++ 绘制组件、最小示例和验证方法。

**想查看已有的具体应用和阶段性成果？**

可浏览 [固件口袋](firmware-pocket/) 与 [亮证](亮证/) 目录。目录中的压缩包与规范文档用途不同，实际内容和使用条件应以相应交付材料为准。

## 阅读与使用提示

本仓库是持续整理中的**工程项目集**，并非一个下载后即可在所有墨水屏设备上直接运行的统一安装包。

不同材料可能面向不同的硬件型号、运行环境和开发阶段。接入规范说明的是设计与协作要求；某个应用是否已实现相应行为、是否适用于特定设备，需要结合该应用的具体版本与测试结果判断。

如果你是第一次接触这个项目，建议先看上面的目录说明，再进入自己感兴趣的子项目；不必从头阅读所有技术文件。
